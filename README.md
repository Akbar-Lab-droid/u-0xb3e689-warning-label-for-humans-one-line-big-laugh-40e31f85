Entry for make.fun's **"Warning Label for Humans: One Line, Big Laugh"** bounty ($5 in USDC).

The entry is one line in `entry.txt` — the safety warning label that should come printed on every human being. At most 160 characters, funny first and plausible second.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) copies the committed `entry.txt` into `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/`), which is what the harness reads.
